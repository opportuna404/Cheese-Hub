# Cheese Hub 🧀

Blox Fruits automation script with complete **First Sea (Sea 1) Island Secrets / Bonus Moments** automation, Auto-Farm, Auto-Gacha, and more.

## 🚀 How to Execute

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/opportuna404/Cheese-Hub/main/Main.lua"))()
```

> [!NOTE]
> For `game:HttpGet` to work without authentication, the repository **must be Public**.
> If the repository is **Private**, GitHub blocks direct raw HTTP requests (`404 Not Found`). To fix this, change the repository visibility to Public in GitHub Settings:
> `Settings -> Danger Zone -> Change repository visibility -> Make public`.

- **Island Secrets (Sea 1)**:
  - Progress tracker showing completed secrets (out of 39).
  - Awakened boss rumor and timer tracker.
  - Auto-completion for all fixed secrets:
    - *Jungle* (Zipline Repair)
    - *Pirate Village* (Windmill Maintenance)
    - *Desert* (Rescue Hasan, Archaeologist's Tablet)
    - *Frozen Village* (Breaking the Ice)
    - *Marine Fortress* (Fortress Flagpole)
    - *Lower Skylands* (Electric Fighting Teacher)
    - *Upper Skylands* (Temple Intel)
    - *Prison* (Escape from Alcatraz, Don Megalo, Lever Jailbreak)
    - *Colosseum* (King's Apprentice, Legendary Creator Statues)
    - *Magma Village* (Evil Slimes)
    - *Underwater City* (Beyond the Bubble, Fishman Karate)
    - *Fountain City* (Fountain Pipe Repair)
  - One-click solvers for all puzzle quests.
  - Middle Town Finale sequence executor.
- **Farming & Leveling**:
  - Auto-Farm Level, Mobs, and Bosses.
  - Auto-Roll Gacha (First Sea level 50+ support with proximity fallback).
